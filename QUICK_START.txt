## 🚀 TO START USING THIS SYSTEM:

### STEP 1: Open Terminal/Command Prompt
Navigate to your project folder:
```
cd e:\web apps\max
```

### STEP 2: Install Dependencies
```
npm install
```

This will install:
- express (web framework)
- cors (cross-origin support)
- bcryptjs (password hashing)
- jsonwebtoken (authentication)
- uuid (unique ID generation)

### STEP 3: Start the Server
```
npm start
```

You should see:
```
🐟 Fish Hub Server running on http://localhost:5000
📊 API available at http://localhost:5000/api
```

### STEP 4: Open in Browser
- Go to: http://localhost:5000
- You'll see the Fish Hub homepage

## 👤 HOW TO USE - STEP BY STEP

### FOR BUYERS:

1. **Register/Login**
   - Click "Login" in top right
   - Click "Register" to create new account
   - Choose "Buyer" as account type
   - Fill in: Email, Password, Name, Phone

2. **Browse Products**
   - Products appear on home page
   - Use search bar to find items
   - Filter by category and price
   - Sort by price or popularity

3. **Add to Cart**
   - Click "Add to Cart" on any product
   - You'll see a notification
   - Cart badge updates automatically

4. **Go to Checkout**
   - Click Cart icon (🛒) in navbar
   - Review items and quantities
   - Click "Proceed to Checkout"
   - Enter delivery address
   - Select payment method
   - Place order

5. **Track Order**
   - Order confirmation shows Order ID
   - Check order status (Coming Soon - full tracking dashboard)

6. **Leave Reviews**
   - After order delivered
   - Click on product
   - Rate and review the item

---

### FOR SELLERS:

1. **Create Seller Account**
   - Register as "Seller" account type
   - Fill in shop name, phone, address
   - Account will be created

2. **Access Seller Dashboard**
   - After login, go to seller area
   - View dashboard with stats

3. **Add Products**
   - Click "Add Product"
   - Fill in: Name, Price, Category, Stock, Description
   - Products appear on marketplace immediately

4. **Manage Orders**
   - See all customer orders
   - Update order status
   - Confirm shipments

5. **View Earnings**
   - Dashboard shows total sales

   - View customer reviews

## 🔗 API ENDPOINTS (For developers)

### Authentication
- POST /api/auth/register → Create account
- POST /api/auth/login → Login
- GET /api/auth/me → Get current user
- PUT /api/auth/profile → Update profile

### Products
- GET /api/products → Get all products
- GET /api/products?category=X&search=Y → Filter products
- GET /api/products/:id → Get single product
- POST /api/products → Add new product (seller only)

### Cart
- GET /api/cart/:userId → Get cart
- POST /api/cart/:userId/add → Add to cart
- PUT /api/cart/:userId/update → Update quantity
- DELETE /api/cart/:userId/remove/:itemId → Remove item

### Orders
- POST /api/orders → Create order
- GET /api/orders/user/:userId → Get user's orders
- GET /api/orders/:orderId → Get single order

### Reviews
- POST /api/reviews → Post review
- GET /api/reviews/product/:id → Get product reviews

### Sellers
- POST /api/sellers/register → Become seller
- GET /api/sellers/me/dashboard → Seller dashboard

## 💡 KEY FEATURES EXPLAINED

### 1. AUTHENTICATION
- Users register with email/password
- Passwords are encrypted (bcryptjs)
- Login generates JWT token
- Token saved in browser, used for API calls

### 2. SHOPPING CART
- Items stored in browser's localStorage
- Persists even if page closes
- Updates product stock when order placed
- Cleared after checkout

### 3. ORDERS
- Status tracking: pending → confirmed → shipped → delivered
- Tracking number generated automatically
- Estimated delivery calculated
- Payment status tracked separately

### 4. PRODUCTS
- Searchable by name/description
- Filterable by category
- Sortable by price/popularity
- Stock automatically updated
- Reviews update product rating

### 5. SELLER SYSTEM
- Multi-vendor marketplace
- Each seller has own products
- Commission tracking ready
- Order management per seller

## 🆘 TROUBLESHOOTING

### Server won't start
```
Error: Port 5000 already in use
→ Change PORT in server.js to 5001
```

### Can't login
```
→ Check email/password are correct
→ Account must be registered first
```

### Products not showing
```
→ Check /data folder exists
→ Seller must be registered to add products
```

### Cart disappeared
```
→ Browser localStorage cleared
→ Check if you're logged in
```

### Checkout fails
```
→ Products may be out of stock
→ Address field might be empty
```
