STEP 8: IDENTIFY THE PROBLEM
=============================
Compare your console output with Step 5 or 7. 

Scenarios:

SCENARIO A: Nothing appears in console
  Problem: JavaScript isn't running
  Fix:
    1. Refresh page (F5)
    2. Check for JavaScript errors (red messages in console)
    3. Try incognito mode
    4. Try different browser

SCENARIO B: ✅ Messages appear but Response status: 404
  Problem: Server routes not found
  Fix:
    1. Server might be crashed
    2. Run: npm install
    3. Restart: npm start
    4. Check if /api/auth/routes exist
    5. Look in server terminal for errors

SCENARIO C: Response status: 400, Response data: { error: '...' }
  Problem: API rejected the request
  Common errors:
    - "Email already exists" → Try different email
    - "Invalid email format" → Use valid email (with @)
    - "User not found" → Wrong email/password for login
    - "Password too short" → Use longer password (8+ chars)

SCENARIO D: ❌ Login exception: TypeError: fetch failed
  Problem: Can't reach server
  Fix:
    1. Make sure server is running (npm start)
    2. Check server terminal for errors
    3. Try: curl http://localhost:5000/api/health
    4. If curl fails, server needs restart

SCENARIO E: Redirects to index.html but not logged in
  Problem: Login worked but page thinks you're not logged in
  Fix:
    1. Check localStorage has token
    2. Run in Console:
       localStorage.getItem('token')
       localStorage.getItem('user')
    3. Should show long token string and user object
    4. If empty, tokens aren't being saved
    5. Check browser Privacy settings allow localStorage

STEP 9: MANUAL API TEST (If UI doesn't work)
============================================
If the JavaScript approach fails, test the API directly.

Open new Terminal and run:

TEST 1 - Check server:
  curl http://localhost:5000/api/health
  
Expected output: {"status":"ok"}

If this fails:
  - Server not running
  - Run: npm start
  - Wait 3 seconds
  - Try curl again

TEST 2 - Register:
  curl -X POST http://localhost:5000/api/auth/register \
    -H "Content-Type: application/json" \
    -d "{\"email\":\"curl@test.com\",\"password\":\"password123\",\"name\":\"Curl Test\",\"phone\":\"0123456789\",\"role\":\"buyer\"}"

Expected output:
  {"message":"User registered successfully","token":"eyJhbGc...","user":{"id":"...","email":"curl@test.com",...}}

If this works → API is fine, issue is in browser JavaScript
If this fails → API has problem, restart server

TEST 3 - Login:
  curl -X POST http://localhost:5000/api/auth/login \
    -H "Content-Type: application/json" \
    -d "{\"email\":\"curl@test.com\",\"password\":\"password123\"}"

Expected output: Same as TEST 2

If this works → API is definitely fine
If this fails → Wrong credentials
