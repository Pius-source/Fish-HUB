COMMON ERRORS & FIXES
====================

Error: "No console messages"
  Fix: Refresh page (Ctrl+F5)
       Or check scripts load: js/api-client.js, js/login-handler.js

Error: "Response status: 400"
  Fix: Read response error message
       Likely: "Email already exists" → try different email
       Or: "Invalid email or password" → check credentials

Error: "Response status: 404 or 500"
  Fix: Restart server: Ctrl+C, npm start

Error: "TypeError: fetch failed"
  Fix: Server not running
       Run: npm start
       Wait 3 seconds
       Refresh page

Error: "❌ AuthManager not found"
  Fix: api-client.js didn't load
       Refresh page with Ctrl+F5
       Check file exists: js/api-client.js

COMMAND REFERENCE
=================

Start server:
  npm start

Check server running:
  curl http://localhost:5000/api/health

Test register:
  curl -X POST http://localhost:5000/api/auth/register \
    -H "Content-Type: application/json" \
    -d "{\"email\":\"test@test.com\",\"password\":\"password123\",\"name\":\"Test\",\"phone\":\"0123456789\"}"

Test login:
  curl -X POST http://localhost:5000/api/auth/login \
    -H "Content-Type: application/json" \
    -d "{\"email\":\"test@test.com\",\"password\":\"password123\"}"

Browser console commands:
  // Check if auth loaded
  console.log(typeof auth);
  
  // Check if user logged in
  localStorage.getItem('token');
  
  // Test login directly
  auth.login('test@test.com', 'password123');
