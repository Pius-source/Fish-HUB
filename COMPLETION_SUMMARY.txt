🔗 API ENDPOINTS (30+ Endpoints)
═══════════════════════════════════════════════════════════════

AUTH (4 endpoints)
  POST   /api/auth/register         - Create account
  POST   /api/auth/login            - Login user
  GET    /api/auth/me               - Current user
  PUT    /api/auth/profile          - Update profile

PRODUCTS (6 endpoints)
  GET    /api/products              - List all
  GET    /api/products?filters      - With filters
  GET    /api/products/:id          - Single product
  POST   /api/products              - Add product
  PUT    /api/products/:id          - Update product
  GET    /api/products/categories   - Get categories

CART (5 endpoints)
  GET    /api/cart/:userId          - Get cart
  POST   /api/cart/:userId/add      - Add item
  PUT    /api/cart/:userId/update   - Update item
  DELETE /api/cart/:userId/remove   - Remove item
  DELETE /api/cart/:userId/clear    - Clear cart

ORDERS (5 endpoints)
  POST   /api/orders                - Create order
  GET    /api/orders/user/:userId   - Get orders
  GET    /api/orders/:orderId       - Single order
  PUT    /api/orders/:id/status     - Update status
  PUT    /api/orders/:id/payment    - Payment status

SELLERS (5 endpoints)
  POST   /api/sellers/register      - Become seller
  GET    /api/sellers/me/dashboard  - Dashboard
  GET    /api/sellers/:sellerId     - Get seller
  GET    /api/sellers               - List all
  PUT    /api/sellers/:sellerId     - Update seller

REVIEWS (4 endpoints)
  POST   /api/reviews               - Create review
  GET    /api/reviews/product/:id   - Product reviews
  GET    /api/reviews/user/me       - User reviews
  PUT    /api/reviews/:id/helpful   - Mark helpful

🎯 HOW TO USE
═══════════════════════════════════════════════════════════════

STEP 1: Install & Start
  npm install
  npm start

STEP 2: Register Account
  - Click "Login" button
  - Click "Register"
  - Choose Buyer or Seller
  - Fill form and register

STEP 3: Browse & Shop (Buyers)
  - See products on home page
  - Search or filter products
  - Click "Add to Cart"
  - Click Cart icon
  - Proceed to checkout
  - Place order

STEP 4: Manage Shop (Sellers)
  - Register as seller
  - Access dashboard
  - Add products (via API)
  - View orders
  - Track earnings

STEP 4: Interact
  - Write reviews
  - Rate products
  - Track deliveries
  - Manage addresses
