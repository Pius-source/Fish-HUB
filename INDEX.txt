                            API ENDPOINTS (30+)
════════════════════════════════════════════════════════════════════════════════

AUTHENTICATION        | Products              | Orders
POST   /register      | GET    /products      | POST   /orders
POST   /login         | GET    /products/:id  | GET    /orders/user/:id
GET    /me            | POST   /products      | GET    /orders/:id
PUT    /profile       | PUT    /products/:id  | PUT    /:id/status
                      |                       | PUT    /:id/payment
Shopping Cart         | Sellers               | Reviews
GET    /cart/:userId  | POST   /register      | POST   /reviews
POST   /add           | GET    /me/dashboard  | GET    /product/:id
PUT    /update        | GET    /sellers/:id   | GET    /user/me
DELETE /remove        | GET    /sellers       | PUT    /:id/helpful
DELETE /clear         | PUT    /:sellerId     |

                            HOW TO USE IT
════════════════════════════════════════════════════════════════════════════════

FOR BUYERS:
  1. Register with email & password
  2. Browse products or use search
  3. Filter by category/price
  4. Click "Add to Cart"
  5. View cart and proceed to checkout
  6. Enter delivery address
  7. Place order
  8. See confirmation with tracking
  9. Leave reviews and ratings

FOR SELLERS:
  1. Register as seller account type
  2. Access seller dashboard
  3. Add products (via API endpoints)
  4. Manage inventory
  5. View customer orders
  6. Track earnings

FOR ADMINS:
  1. Access /data folder for JSON files
  2. View all users, products, orders
  3. Manage platform data
  4. Monitor system
