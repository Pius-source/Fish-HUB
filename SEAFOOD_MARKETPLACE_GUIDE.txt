BUYER WORKFLOW
==============

1. REGISTER AS BUYER
   - Go to: http://localhost:5000/login.html
   - Click "Register"
   - Fill in: Email, Password (6+ chars), Name, Phone
   - Account Type: Choose "Buyer"
   - Click "Register"
   - Redirects to home page

2. BROWSE PRODUCTS
   - Home page: http://localhost:5000/index.html
   - See products from all sellers
   - Search by product name
   - Filter by category (Fish, Shrimp, Crab, etc.)
   - Sort by price or popularity

3. ADD TO CART
   - Click "Add to Cart" on any product
   - See notification "✅ Added to Cart"
   - Cart count updates in navbar

4. VIEW CART
   - Click "🛒 Cart" in navbar
   - See all items with prices
   - Update quantities
   - Remove items
   - See total price

5. CHECKOUT
   - Click "Place Order" in cart
   - Enter delivery address
   - Choose payment method
   - Complete order
   - Get order confirmation

SELLER WORKFLOW
===============

1. REGISTER AS SELLER
   - Go to: http://localhost:5000/login.html
   - Click "Register"
   - Fill in: Email, Password (6+ chars), Name, Phone
   - Account Type: Choose "Seller"
   - Click "Register"
   - Redirects to dashboard automatically

2. ACCESS SELLER DASHBOARD
   - As logged-in seller: Click "📊 Seller Dashboard" in navbar
   - Or go directly to: http://localhost:5000/seller-dashboard.html
   - Dashboard shows:
     ✅ Total products
     ✅ Total stock
     ✅ Total sales

3. ADD NEW PRODUCT (SEAFOOD)
   - Click "Add Product" tab
   - Fill in product details:
     • Product Name (required): e.g., "Fresh Atlantic Salmon"
     • Description: Details about the fish
     • Category (required): Fish, Shrimp, Crab, Lobster, etc.
     • Price (required): $XX.XX format
     • Stock Quantity (required): How many units available
     • Origin: Where it's from (e.g., "Atlantic Ocean")
     • Product Icon: Emoji (optional, default: 🐟)
   - Click "Add Product"
   - See confirmation: "✅ Product added successfully!"

4. MANAGE PRODUCTS
   - Click "My Products" tab
   - See all your products in a grid
   - View product details:
     • Product name
     • Price
     • Stock quantity
     • Category & origin
   - Actions available:
     • Edit: Modify product details (coming soon)
     • Delete: Remove product from inventory
   - Stats shown:
     • Total Products count
     • Total Stock units
     • Total Sales ($)

5. VIEW ORDERS
   - Click "Orders" tab
   - See table of all customer orders:
     • Order ID
     • Customer name
     • Order total ($)
     • Order status (pending, confirmed, shipped, etc.)
     • Order date
   - Track when customers purchase your products

TECHNICAL DETAILS
=================

Backend:
- Node.js + Express server on port 5000
- REST API with 30+ endpoints
- JSON file-based database
- JWT authentication
- Password hashing with bcrypt

Frontend:
- HTML5, CSS3, Vanilla JavaScript
- No external dependencies (clean)
- LocalStorage for cart persistence
- Responsive design (mobile-first)

Database:
- /data/users.json - User accounts
- /data/products.json - Product catalog
- /data/sellers.json - Seller profiles
- /data/orders.json - Customer orders
- /data/cart.json - Shopping carts
- /data/reviews.json - Product reviews
- /data/categories.json - Categories

SUPPORT
=======

If something doesn't work:

1. Check server is running:
   - Terminal should show:
     🐟 Fish Hub Server running on http://localhost:5000
     📊 API available at http://localhost:5000/api

2. Clear browser cache:
   - Ctrl+Shift+Delete (Windows/Linux)
   - Cmd+Shift+Delete (Mac)
   - Select "Cookies and cached images"

3. Log out and log back in:
   - Click logout in navbar
   - Go to login page
   - Log back in

4. Check the browser console:
   - F12 to open Developer Tools
   - Look for red error messages
   - Share the error message

5. Restart everything:
   - Stop server: Ctrl+C
   - Start server: npm start
   - Refresh browser: F5
