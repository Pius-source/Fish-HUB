## 🐛 TROUBLESHOOTING

### Server won't start
**Problem:** `Error: listen EADDRINUSE: address already in use :::5000`
**Solution:** Change port in server.js to 5001

### Login doesn't work
**Problem:** "Invalid email or password"
**Solution:** 
- Check email spelling
- Make sure you registered first
- Try test account: `buyer1@test.com`

### Products not showing
**Problem:** Empty product list
**Solution:**
- Check `/data/products.json` exists
- Products created via API endpoints
- Or check server console for errors

### Cart not persisting
**Problem:** Items disappear on refresh
**Solution:**
- Make sure logged in
- Check browser localStorage enabled
- Clear browser cache and retry

### Checkout fails
**Problem:** Order not created
**Solution:**
- Ensure stock available
- Fill all required fields
- Check server console for errors
